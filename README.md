# Aily

Build your intuition for AI.

A static learning workspace with a Python reference, three introductory ML chapters, two interactive visual experiments, five decision-making challenges, and a searchable glossary.

Serve `dist` with any static HTTP server. Navigation uses URL fragments. Chapter completion is stored only in this browser’s local storage. Python snippets run in the learner’s own environment. The overfitting experiment is explicitly a constructed illustration, not a fitted model.
